# Amazon eCommerce SQL Analysis

This repository contains SQL scripts for analyzing an **Amazon eCommerce dataset**.  
It is designed to provide insights into sales performance, customer behavior, product trends, and revenue patterns.  

---

## **Purpose**

The goal of this repository is to:

- Analyze **total sales and revenue** for different products and categories.  
- Identify **top-selling products** and **high-value customers**.  
- Understand **monthly revenue trends** and seasonal patterns.  
- Explore **customer locations**, **payment methods**, and **order statuses**.  
- Support **data-driven decision-making** for eCommerce operations.  

---

## **Dataset**

The queries in this repository are based on a dataset named:  
`amazon_sales_data 2025`

The dataset contains the following key columns:

- `order_id` – Unique identifier for each order  
- `order_date` – Date and time of the order  
- `product` – Product name  
- `category` – Product category  
- `price` – Price of the product  
- `quantity` – Number of units sold  
- `total_sales` – Total sales amount  
- `customer_name` – Name of the customer  
- `customer_location` – Location of the customer  
- `payment_method` – Payment type used  
- `status` – Order status (e.g., delivered, pending)  

---

## **Key Features**

- Total revenue and quantity analysis  
- Category-wise and product-wise revenue trends  
- Top customers and high-value locations  
- Payment method and order status analysis  
- Insights into repeat customers and monthly revenue patterns  

---

## **Usage**

1. Clone or download this repository.  
2. Open the SQL file(s) in **MySQL Workbench** or any SQL client.  
3. Execute the scripts to analyze your dataset.  

---

## **Notes**

- Ensure that your table structure matches the dataset used in the scripts.
